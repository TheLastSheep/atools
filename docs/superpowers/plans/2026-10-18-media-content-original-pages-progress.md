# ATools：文件／图片输入与原插件页面进展（batch34）

本轮状态为 `progress`，总体目标继续保持 `active`。已完成文件／图片输入的匹配与激活链路，并完成三份完整原插件页面的指定浏览器流程。大部分 ZTools 插件直接使用、原生编辑器输入以及与 ZTools/uTools 的同机体验对照仍需继续验收。

## 可运行的变化

- 粘贴文件或图片后，搜索框展示固定内容标签，继续输入可筛选相应插件。文件原始顺序、名称、路径及类型作为 `files` 载荷传入；图片以完整 data URL 作为 `img` 载荷传入。
- 文件候选使用主机实际文件信息，支持数量、文件／目录、扩展名与名称规则。静态及动态插件声明使用同一份目录投影和缓存索引。
- Finder 文件缺少浏览器路径时，显式粘贴只请求一次原生媒体读取；带图片 File 的路径判定先查询文件，不再重复复制原生图片。普通文字粘贴仍保留光标、选区和原有文字输入行为。
- 清空、替换、隐藏、页面切换、目录刷新及激活取消会使旧回包失效。直接打开插件的订阅在取消、正常关闭及延迟返回时均释放。
- 插件收到的文件／图片与普通激活共享权限和 TaskRun 管线。显式媒体读取登记为 `atools.clipboard.read_media`；MCP 返回元数据摘要，人机入口原始载荷保留在当前任务中。
- 权限、执行记录与诊断只记录摘要。新工具参数在共享任务初始化入口的内存默认值处理前后检查，覆盖后台任务写入 Created 记录之前的路径。
