本批补齐“主页面不使用 Node、子窗口首次使用 Node”的按需授权链路，并修复原版英语练习子 preload 因缺少 `webFrame.setZoomFactor` 而中断初始化的问题。最终隔离桌面流程通过 35 项检查。整体目标仍在进行：尚不能据此认定大部分 ZTools 插件可直接使用，或 UI/交互已达到 ZTools、uTools 水平。

完整范围、验证日志、历史失败与待验收项见[交付索引](../../../output/plugin-input-2026-10-18/batch31-delivery-v1.json)。

## 已交付的运行时行为

- 子入口通过现有权限和 TaskRun 流程申请 Node；拒绝后不执行、不自动重试，关闭整个插件后可重新申请。
- 选中的包内 preload、受支持静态依赖、安装身份及代码修订在授权前后复查。严格路径拒绝无法完整绑定的第三方包、包别名和未支持的 require 写法；保留旧主入口及提示扫描行为。
- 这只是有预算的静态子集检查，不是完整 JavaScript 依赖证明、不可变文件系统，或前端与原生执行字节的原子握手。
- `webFrame` 仅支持当前文档的同步 `setZoomFactor` / `getZoomFactor`。只接受有限正数，默认 1，通过当前文档 CSS zoom 应用；正常路径没有新增长期监听、轮询、定时器或观察器。
- 文档根节点尚未建立时，使用一次性的文档就绪与当前 Window 退出监听。退出清理两类监听，应用失败保留最后成功值，不自动重放。
- 未提供 Chromium 原生缩放、DPR、同源窗口联动或其它 webFrame API 的等价保证。接口定义参考 [Electron webFrame](https://www.electronjs.org/docs/latest/api/web-frame)，退出事件目标参考 [HTML 文档生命周期](https://html.spec.whatwg.org/multipage/document-lifecycle.html#unload-a-document)。
