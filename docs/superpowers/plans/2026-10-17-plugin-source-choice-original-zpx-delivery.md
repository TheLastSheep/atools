# 第二十七批：插件来源选择与原版 ZPX 实际运行

本批为已验证的阶段进展，整体 goal 保持 active。生产导入、界面选择和一个原版归档的实际运行均得到新增证据；多数 ZTools 插件业务可用率、完整前台体验及完整应用资源预算仍未验收。未暂存、提交、推送或替换安装版应用。

## 生产行为

- 扫描包含 manifest 的源码目录时，保留目录候选并发现同层 ZIP/ZPX/ASAR。停止进入该插件的子目录，跳过依赖、VCS 与自动遍历的 dist 子树，不跟随符号链接。
- 源码与安装包可能安装为同一插件，界面默认不选这类多来源组。用户可用 checkbox 或 Tab/空格明确选择一个；“选择无冲突来源”保留该选择。重试和报告合并不会重新带回已被替代的失败来源。
- 两条后端导入入口共享批次预检。不同来源共用安装冲突 key 时全部拒绝该组，其他插件可继续导入；这不是整个批次的原子事务。macOS/Windows 的冲突 key 保守地忽略 ASCII 大小写，数据库 ID 与实际目录名保持原值，不探测卷的大小写规则。
- 420px 下失败原因与路径完整换行，checkbox 焦点框保持原生尺寸。900/420px 浏览器布局、实际 checkbox 选择及模拟 IPC 路径验证通过；没有将静态浏览器结果当作原生物理输入证据。
- 复用现有受限读取器修复 ASAR 外置资源既有的检查后读取竞态与无界读取。导入器拆分为发现、检查、计划和归档模块；公共插件 DTO 提取后 types.ts 为 483 行。本批改动的代码文件均低于 500 行，无新增依赖。
