# 编辑器原生输入诊断交付（Batch 41）

本批为进展交付，目标继续保持 active。纯文本、JSON 原版插件的系统输入验收均未通过；新增完整原版插件验收数为 0。尚不能声明大多数 ZTools 插件可直接使用、与竞品交互持平或完成正式验收。本批修改集中在显式启用的隔离验收路径，未更改生产窗口激活策略或原版插件源码。

补齐了三层证据：宿主与插件页面从阶段开始前记录有界事件；原生代码按实际主 WKWebView 指针和最多 64 个 NSView 祖先判断第一响应者归属；固定控制器在点击后必须获得当前 PID、用例、阶段、动作序号和认证文档的确认，才可继续键入。格式化点击同样必须等到该阶段确认后才能进入下一阶段。

事件时间线每个页面最多保留 128 条，计数饱和于 8192；原生事件最多保留 128 条；控制器阶段最多 32 条。诊断不读取键值、输入数据、编辑内容或选择区，不记录原始 AX 树、窗口名称或编辑器名称。各上下文使用自己的单调时钟，不能直接相减。原有严格可信编辑事件、实际渲染文本、格式化、诊断恢复和持久化断言没有放宽。

固定操作仍只有 plain-alpha、plain-beta、json-valid、json-format、json-malformed、json-recovery。ABC 只可从已启用输入源中临时选择；只有本控制器选择的 ABC 仍为当前输入源时才恢复原输入源，用户中途另选的输入源不会被覆盖。私有交换目录使用 `/private/tmp`、0700、当前用户所有和规范路径；消息限制 4096 字节，绑定文档与一次性随机数，确认最多等待 3 秒；固定动作总期限 16 秒。检查脚本只读，不激活窗口。
