# Batch 37：原版插件的搜索结果、页面连续性与原生资源交接

状态：持续开发中。没有创建 Git 提交或推送；没有宣布大部分社区插件已可直接使用。

目标已扩展为补齐社区插件所需的共用兼容层，提供直接安装或一键转换路径。本轮 MainPush、Node、权限和资源响应属于共用底层能力；插件清单、兼容分级与业务验收分别记录。

## 已实现的行为

- 原版计算纸与书签样例已接入搜索结果；输入表达式或固定书签关键词时可直接返回结果，静态搜索独立返回。
- 查询启动与进入插件分开；插件返回 `true` 时才从结果选择进入原页面。缺少选择回调时留在搜索。
- 独立的“打开插件”操作保留当前 iframe、Window、document 和当前查询；选择对象留在原页面中保持引用身份。
- 输入法组合输入、正在关闭的实例、晚到的静态结果和选择失败均有回归覆盖。失败会关闭相关实例并撤销该次授权。
- 查询启动可以在同一权限队列中继续请求 Node、插件数据或路径权限；正在等待子权限的父请求不再挡住子请求。
- 原生资源响应在主线程完成最终授权核验及交付。后台线程不再持有全局资源锁等待 WebKit 主线程。

## 已验证的边界

浏览器夹具的 9 项检查覆盖原版计算纸、原版书签及明确标注的合成插件；Node 书签读取使用真实 CJS 加载图，打开浏览器的操作使用记录接收端。浏览器中的原生权限、任务和资源服务是替身，不作为桌面证明。

最终源码上的 MainPush 原生 v7 检查通过 16 项断言，使用真实 App、导入器、权限队列、TaskRun、原生资源管理器及 Node。两份清理状态分别采于前端卸载后和显式原生清理后，相关实例、授权、传输、活动读取及排队请求均为零。114 条任务全部终态，其中 15 条 MainPush 任务为 14 成功、1 取消；审计条目共 122 条。588 份原生夹具选择的源码与最终冻结一致。此前 v5 也通过，审计数为 123，两个运行分别保留。

原生 MainPush 的输入是程序派发的夹具 DOM 事件，未证明硬件输入。6.5 秒权限等待验证的是实际队列、DOM 对话框及恢复，没有像素或 AX 可见性断言。隐私检查仅扫描本次 4 个固定字符串；不能推广为通用秘密检测。

书签来自隔离的固定 Chrome/Edge 文件；没有操作真实浏览器资料，未执行会打开浏览器的原生选择回调。系统主剪贴板由 `NoClipboard` 禁用，宿主测试使用独立命名剪贴板。Node 授权不等于 OS 沙箱。

## 性能预算

- 150 ms 独立查询防抖；最多两个插件实例、一个启动过程、每实例一个在途查询和一个待执行的新查询。
- 每插件最多 20 行，总计最多 40 行；原始结果对象的逻辑 JSON 预算为 16 KiB，跨页面响应为 256 KiB。
- 启动、查询和选择的执行时限分别为 5 s、1.2 s、3 s，真实权限等待暂停执行计时；空闲实例在 30 s 后释放。
- 原始对象预算拒绝 Map、Set、自定义原型、额外数组属性、非枚举引用、访问器等不支持的形状，保留允许的普通对象和稠密数组的原始身份。这是逻辑数据预算，不是 JS 堆或 RSS 限额。
- 已完成的生产构建：初始 JS 为 360,434 B，预算为 573,440 B。相比 batch 36 增加 17,686 B。
- 最终串行测量保留 200 个查询样本，其中 198 个低于 25 ms；媒体 `unique6` 与 `ruleBoundary8192` 的首次查询分别为 56.657292 ms、28.681542 ms，预算未通过。首次失败后只补测尚未执行的项目，没有重跑覆盖失败。
- 34 个构建样本独立于查询预算；16 个文本及 12 个媒体配额拒绝样本保留。五个新进程的程序复用测量中，冷安装中位数为 565.357792 ms，真实规则变更为 290.317417 ms，也不计入查询时长。

慢样本均使用较大的 RegexSet。现有计时已排除程序编译，但首次搜索可能仍创建引擎缓存或懒 DFA 状态；目前仅为源码支持的候选，未取得 CPU／引擎剖析，不能确认根因或归因于外部负载。

未证明整棵应用进程树的内存预算或相对竞品的同机性能优势。原生管理器计数归零不能推导为全部 OS/WebKit 进程退出。

## 尚未关闭的差距

- 提升后的查询 iframe 保持原沙箱，原生 `window.open`／DOM popup 与普通入口仍有兼容差异；没有通过重载原页面或放宽隐藏查询沙箱掩盖差异。
- 真实同步死循环不能依靠同一 WebView 内的 JS 定时器强制停止，执行时限不构成任意第三方代码的 CPU 隔离保证。
- 固定 JSON／纯文本编辑器的完整原生输入链，以及更多原版插件业务流程，仍需分别验收。
- 两项媒体首次查询的 25 ms 门禁仍失败，需要分离实际 CPU 与引擎首次搜索成本后修复。
- source-only 前端包目前只有 RequiresBuild 分类，尚无已验证的离线、有界一键构建转换；后续以明确的工具链、输入输出、资源限额和取消清理契约实现，不将历史候选数当成当前兼容率。
- 安装清单、资源存在和兼容分级不能替代多数原版插件直接可用的证据。
