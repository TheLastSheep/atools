# ATools 搜索分页与窗口几何兼容交付（batch39）

状态：已完成本轮局部开发与验证，长期目标继续进行。2026-10-19，本地 macOS 工作区；无提交、推送、依赖安装或外网请求。原版插件多数可直接使用、ZTools/uTools 整体体验对齐仍未验收。

## 本轮结果

搜索结果增加 PageUp/PageDown，按当前可见列表高度移动，沿实际分组后的顺序选择并滚动到可见位置。搜索词和执行状态保持稳定。输入法组合、修饰键、权限框、菜单、插件输入区继续保留原来的键盘归属。分页位置查找使用已有虚拟列表索引和二分查找，不增加 1200 行 DOM。

共用窗口适配层的 getBounds/getSize/getContentSize/getMinimumSize/getMaximumSize/getPosition 现在同步返回最新宿主确认的快照及独立副本。此前 Promise 返回值使原版打字插件读取到空尺寸，涂改插件拖动计算得到无效坐标。原版源码中的精确函数声明和回调保持不变，修复落在适配层。

快照包含创建请求、创建者文档、窗口实例、子文档及递增版本身份。未就绪或关闭时明确报错；修改被拒绝不更新缓存，异步修改的错误仍可观察。getter 不发 IPC，也不轮询。异步 setter 同一调用栈内同步生效不在承诺范围。

独立审查发现“创建者收到更新但子文档尚未监听”会被全窗口去重误判为已送达。已在真实 ready 接线中补同步到当前子文档，校验实际源与当前文档身份；发送失败进入原有失败路径，不报告 ready。保留 3 条修复前失败，实际生产函数抽取回归通过。

## 保留的问题与修复记录

完整回归首次有 8 项失败，原因是旧 feature-entry 测试夹具缺少新 factory 的显式依赖；仅增加真实导入与作用域注入，原 8 项业务断言未改。旧 menu/IPC 抽取夹具也补齐真实新依赖，不模拟成功的几何发布。

桌面 v1–v3 失败记录保留。原因是本轮新夹具拼接的 IIFE 末尾漏分号，使后段初始化被解析为调用前段返回值。已修复并新增完整生成脚本的 VM 初始化检查；精确移除边界分号可重现 TypeError。v4 在原有业务断言上通过，未缩小检查范围。

原版纯文本编辑器的物理输入，以及 JSON 编辑器的物理输入、格式化、诊断和恢复仍未通过正式验收。本轮没有 CUA、AppleScript、系统输入源或物理输入操作。焦点探索未找到足以修改生产焦点逻辑的证据，不以程序赋值替代输入验收。

本轮没有更改 Rust matcher。batch38 的 200/200 查询小于 25ms 是上一轮结果；其 34 次构建样本不混入查询，既有测试有 9 次未计时的基数检查，不声称进程冷启动。batch37 两个超预算样本的原因和可靠性修复仍未证实，不以本轮包体或 getter 检查消除历史失败。
