# Batch 38：本地源码转换、安装反馈与查询诊断

状态：本轮限定实现与本地验收完成，总体目标继续 active。没有创建 Git 提交或推送。大部分原版社区插件可直接使用或转换，尚未得到业务验收证明。

本轮把“需要构建”的分类推进为实际本地转换：用户主动检查项目，查看权限说明，再由真实构建、产物校验和共同安装流程完成替换。失败或取消保留旧安装；最终原生夹具通过 18 项检查。当前支持范围是 macOS 上满足既定本地依赖与构建配方要求的项目。

## 实现与交互

- 源码目录的 `requires_build` 和 `incomplete` 状态均提供主动检查入口；二者不能进入直接导入勾选。后者即使缺少错误消息，也保持不可直接导入。宿主的发布包分类没有改变。
- 检查不随列表扫描批量构建。已有完整发布目录继续直接导入；转换接受已有自身本地依赖、精确匹配的 Vite 声明／锁记录／安装版本，以及 `vite build` 配方。
- 不运行包管理器，不下载或安装依赖，不删除原项目 dist，不去掉项目自身检查来声称原配方通过。
- 权限弹窗说明目录、构建和替换；授权续跑保留原 TaskRun。数据库领取 Running 后关闭已消费弹窗，状态和取消入口继续可达。
- 单次转换身份绑定任务、发起者、输入目录、源码摘要、插件 ID、版本和覆盖选项。成功提示还要核对已持久安装结果，不能用请求已发出或产物存在代替成功。
- 状态、预检、安装后目录读取设观察截止时间，迟到回复不会覆盖新观察。超时保留已安装结果，允许重新读取，不自动重复安装或启动。
- 构建之前和之后分别检查原源码摘要；实际复制进私有工作区的输入也匹配批准摘要。安装复用现有发布包校验、生命周期写门禁、目录替换和数据库流程。
- 关闭面板只结束观察；运行取消由独立监督器完成。安装提交开始后拒绝取消；没有活动构建时明确拒绝取消。

## 执行与资源边界

每个宿主进程最多一个构建任务。可信宿主先进入独立 bootstrap，再建立进程组、资源限制及 SBPL 环境；未信任 Node 启动前关闭非标准继承描述符。生产启动前回调没有执行原先缺少异步信号安全依据的操作。目录遍历使用目录描述符，拒绝链接、特殊文件和原生 addon，明确处理 `readdir` 错误。

单文件 32 MiB、目录树 128 MiB、4096 条目，构建双输出流合计最多捕获 64 KiB。受监督进程运行时限 120 秒，回收等待 3 秒；目录与字节上限用于准入／验证，不是实时磁盘配额，也不是整个 API 总时限。文件描述符与文件大小限制不构成所有后代的总 CPU/RSS 限额，回执保留 `fullTreeContainment=false`、`aggregateResourceCaps=false`。

构建环境不继承用户凭据或 Node 注入变量；私有工作区可写，本地依赖只读。原生测试验证了受控外部文件读写及 IPv4 回环访问拒绝；没有逐项证明 IPv6、UDP、Unix socket、Mach 或全部文件系统情况。当前仅验证 macOS 27，不能外推为其他平台支持或完整后代进程隔离。

清理未知状态先于完成信号发布，后续构建保持关闭，并在私有任务根保留恢复记录。隔离范围是当前进程，没有跨重启恢复门禁。安装成功后，宿主专用产物工作区若遭遇极端删除错误，可触发后续隔离而任务已记录成功；它不在未信任构建的可写范围内，此诊断边界仍保留。

## 性能解释与后续

本次测量期间自己的原生、构建和其他测试已结束，固定两组 Rust 查询依次执行，预算未改，也未在原测试之外增加预热或失败重试。原测试的 9 个生态文本输入会先用独立 index 做未计时查询以建立预期数量，所以不能声称进程冷查询或完全没有未计时查询。16 条文本配额拒绝消息在原始日志中完整保留；12 条媒体拒绝的错误码由通过的源码断言验证，日志只打印空结果。

仅测试生效的媒体墙钟／线程 CPU／分阶段诊断中，24 对结果与错误一致。此次正式固定样本通过，仍不能解释或消除 batch 37 的 56.657292 ms、28.681542 ms 首次媒体查询失败；其原因与跨运行可靠性仍待确认。本轮未改变生产匹配算法，也没有新测完整进程树 RSS、应用冷启动或同机竞品交互。

有限元数据调查的 10 个候选中，两个带自身本地依赖的原项目已有完整 dist，另八个源码候选缺少各自依赖。这不是全生态兼容率；没有借用宿主依赖并声称原版源码转换通过。

下一步继续推进具备真实自身依赖的原版源码转换、更多原版插件业务流程、同机 UI／交互与资源预算。此前 JSON／纯文本编辑器完整固定输入、格式化和诊断恢复仍未通过。本轮未操作系统输入源或发送真实键盘输入，已授予的限定授权没有扩展到其他动作。
