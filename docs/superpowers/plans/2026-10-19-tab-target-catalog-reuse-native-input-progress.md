# ATools batch36：Tab 原文启动、规则编译复用与原生输入验收

这是继续开发记录，不是“大多数 ZTools 插件可直接使用”的完成声明。目标仍是同时改善启动器交互、原版插件实际可用性和性能；本轮没有提交、推送或修改已有发布状态。

## 本轮交付范围

- Tab 的“目标命令”模式可以选择固定插件命令，通过插件归属和命令 code 保持身份。按 Tab 将搜索框的原文传给目标，保留 Unicode、换行和首尾空白，零搜索结果也可启动。默认导航模式、Shift+Tab、输入法组合态、菜单和非搜索面板继续遵守原有键盘规则。
- 目标缺失、禁用、歧义或尚未配置时保留输入，并提供可见、可点击的设置入口。错误信息使用原状态栏高度；关闭首页最近记录以及空输入时也有反馈。正常和 480px 窄窗口都做了真实鼠标点击与命中检查。
- 迟到的目录读取、原生描述符和生命周期订阅返回后，若输入、目标、面板或固定文本/文件上下文已变化，丢弃旧面板激活。复用现有取消回调和清理路径。原生 TaskRun、窗口或宿主状态可能已在取消前完成，这不是原生业务执行回滚保证。
- 每个 Database 保留至多一份最近验证的文本规则编译结果。元数据变更、不涉及规则的动态命令变更以及首次目录快照复用这份结果；真正变更规则仍执行完整规则集合的编译和配额验证。候选只在事务提交后发布，拒绝不替换旧 Arc。未支持规则的分类缓存也按精确内容比较并计入现有逻辑预算。
- 设置保存队列和防抖抽成有独立职责的模块，原 settings.ts 从 564 行降到 500 行。其余新模块保持在 500 行以内；三个历史巨型文件只做本轮接线。

本轮 42 个代码文件：28 个基于 batch35 修改，14 个新增。1332 个显式选定输入在冻结时核对；基线漂移均有归属。选源清单不是编译器完整依赖闭包。继承的其它脏文件和锁文件不属于本轮改动。

## 原生编辑器证据要求

用户已批准：仅在本次临时 ATools 的纯文本和 JSON 编辑器执行固定夹具输入；临时切至已启用的 ABC 并恢复原输入源。不使用剪贴板或操作其它应用。

本轮新增有界、无原文的事件时刻焦点分类，区分编辑器可见且有焦点、编辑器可见但无文档焦点、其它焦点、隐藏和未知。只在可信 beforeinput/input 回调内采样，没有轮询或新增监听器。总数、溢出、深拷贝、清理和隐私合同均有验证，原验收门禁保持不变。

临时控制器增加六项布尔诊断：应用记录存在、记录报告终止、POSIX PID 存在探测、bundle 匹配、前台匹配、既有 guard 是否通过。AppKit 记录和零信号 PID 探测是不同观察，不能互相替代；PID 存在也不是完整存活证明。19 项编译后边界检查通过。AX 检查脚本只修正节点编号序列化，保留应用作用域、80 节点上限和 AppleScript 事件超时；父进程另有 8 秒墙钟截止。

实际原生结论必须同时保留：精确文本、可信事件、可见与焦点、JSON 真实格式化点击、错误诊断与恢复、输入源恢复、TaskRun/drain 和临时环境清理。`hardwareHumanInputVerified` 保持 false；控制器成功发出动作不是编辑器业务验收通过。

本轮三个实际原生尝试均未通过完整门禁：

| 尝试 | 已观察到的证据 | 未通过的边界 |
| --- | --- | --- |
| 纯文本 v1 | alpha 原文准确，73 bytes；可信 keydown 74、beforeinput/input 各 71；142 次编辑时刻观测均可见且编辑器有焦点；mousedown/click 各 1 | pointerdown 为 0，alpha 没有形成通过 proof，beta 未进入 |
