# ATools 第 32 批：菜单焦点与动态插件命令

本批完成菜单取消后的焦点交接，以及插件动态命令的同步接口、持久化、搜索索引和 MCP 能力发现。目标继续进行；尚未证明 ZTools 大部分插件可直接使用，也未完成与 ZTools/uTools 的同机体验对比。没有创建提交或推送。

## 已实现行为

- 点击空白或滚轮关闭菜单后，恢复搜索框和原查询；点击外部输入框、按钮或编辑区时，保留目标焦点。
- 菜单失焦、窗口失焦和新的焦点请求会使旧的延迟恢复失效；首页悬停不再抢走菜单的键盘选择。保留原有 Escape、Tab、动作完成和输入法处理。
- `window.ztools` / `window.utools` 的 `getFeatures`、`setFeature`、`removeFeature` 通过现有私有数据通道同步返回数组或布尔值。缺少授权时触发现有权限申请，不保留或重放写入。
- 动态声明单独存入 SQLite，JSON 和搜索投影在同一事务提交。动态命令不会覆盖静态声明；相同内容重复写入不重建缓存；读取只返回动态命令。
- 搜索、原命令激活与 MCP `atools://capabilities` 使用同一真实目录。独立复查发现原 MCP 聚合只读 manifest 后，已改为共享数据库目录，并覆盖新增、修改、移除、禁用、恢复和卸载。
- 真实变化在任务成功且文档会话仍有效时发出已有刷新事件。声明正文和命令内容不写入任务日志。没有新增后台服务或轮询。

接口依据为 [ZTools 官方插件 API](https://github.com/ZToolsCenter/ZTools-doc/blob/main/docs/plugin-api.md)。额外支持的批量形式受同样的事务和额度限制。

## 原插件验证范围

组件测试使用了两个未改动的完整业务函数：`memo-quick-paste` 的 `getTagOptions`（372 字节）和 `url-wizard` 的 `setFly`（778 字节）。前者覆盖同步读取后筛选、排序及图标更新；后者覆盖设置、筛选、移除，使用固定本地图标跳过联网分支。

这两组测试运行实际序列化桥接，传输使用显式同步 XHR 替身，不是原生宿主或完整插件验收。完整原文件与函数均有 SHA-256 指纹，未改原插件。既有 14 个原始案例登记仍分为 9 个完整目录、1 个 ZPX、4 个发布件，不能据此计算完整插件通过率。

## 性能与边界

| 检查 | 当前结果 | 口径 |
| --- | --- | --- |
| 首屏 JavaScript | 321,431 B / 573,440 B | 默认生产构建，未压缩；比上批增加 1,581 B |
| 插件面板独享懒加载静态依赖 | 429,173 B | 包括传递依赖；比上批增加 1,558 B；面板组件本身为 241,283 B |
| 1,200 条命令搜索 | 20 个样本，最慢 1.234625 ms / 25 ms | 串行执行；含新索引首次搜索与热搜索，排除索引构建、进程启动、IPC 和 DOM |
| 动态命令单次写入中位数 | 31.89 → 20.12 ms | 同一 debug 配置、16 个相同依赖、5 轮各 32 次写入，共 320 个前后样本 |
| 32 次写入总耗时中位数 | 1,027.13 → 667.10 ms | 删除每次写入时重复构建后丢弃的拼音/正则索引，复用相同额度计算 |

配对写入实验没有丢弃样本或放宽额度；新版本单次最慢 43.20 ms，最后一次冷目录读取中位数 29.25 ms。该实验不属于 25 ms 搜索门禁，也不能代替原生启动、RSS 或生产延迟。早期依赖图不一致的样本保留并排除，最终比较含完整临时源码及两处变化的前后原文。

每插件最多 1,000 个动态命令，每次批量或过滤最多 128 项，单声明 16 KiB、每插件 256 KiB，并保留全局目录数量、命令数、元数据和索引额度。静态保留 code、跨插件相同 code、非法输入或超额写入整体回滚。现有全局 code 唯一约束仍是兼容性限制。

`mainHide`、`platform` 和自定义 JSON 字段保留不等于行为对齐；agent 可执行权限不会因动态命令而提升。已开始的有限 SQLite 事务可能在文档关闭前完成，本批没有宣称导航/撤权与数据库提交之间具有原子保证。
