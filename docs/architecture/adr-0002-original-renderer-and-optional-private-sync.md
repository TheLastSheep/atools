## 需求依据

用户提供“使用 Tauri v2（多 Webview 架构）+ Rust 原生系统层 + Axum 同步服务端 + AI Agent 自动化流水线”的目标，并明确要求按目标执行；随后明确不用 Claim、直接推进。第二份 Gemini 补充被用户指定为参考，不作为已验证的接口契约或性能证据。

第一份原文及 SHA-256 保存在 `output/atools-replication-2026-10-26/goal-input.txt` 与对应任务证据中。其摘要为 `49b2de0b640fb0e20df09c7bf9f8bc3c99c02bf68abe50bca08eb26b6af118e9`。

旧北极星第 4.2 节排除服务端开发。本决策明确扩展可选私有同步范围，实施前同步修订北极星，不静默绕过旧约束。

## 决策

1. 原 ZTools 主 renderer 固定为上游 commit `9b15fb1a2a9f3ec886016632761c7bb21e39557a`；Vue、CSS 和版权信息保持原样，用独立构建入口与类型化宿主适配接入。构建及适配证据不足时不覆盖当前默认入口。
2. 允许独立 Rust/Axum 私有同步服务。以 `ZToolsCenter/ztools-sync-server` commit `8ae1e14fd1071b6762fdb59f05162bc0779a5564` 的真实协议为依据，覆盖认证、WebSocket 文档同步、checkpoint 和附件等纵向行为。
3. 服务是可选部署件，不作为桌面核心依赖；不建设公开账号、评论、插件市场或社区。默认桌面体验继续无需账号、网络或 LLM。
4. 服务使用独立数据库和目录。现有桌面 SQLite、插件存储、TaskRun 及权限体系继续保留；不因技术清单提到 LMDB 而自动迁移或删除用户数据。
5. 按现有真实接口和数据契约实施。缺少的平台/运行时能力明确显示不可用或未验；禁止用通用任意 IPC、伪成功返回、无权限的代理或修改原版 UI 来掩盖缺口。
6. 同步 XHR、Node CJS、子 WebView、窗口分离和来源隔离沿用已有受约束机制并补验，不据参考文档承诺 0.2ms、99% 或 100%。

## 验收与迁移

- 新增作者代码文件不超过 500 行；只读第三方上游作为固定输入，不机械拆改其 Vue/CSS 来满足本仓库作者代码的规模要求。
- 源码、宿主适配、原生调用、浏览器可见行为、数据协议及发行验收分别记录。
- 原版 UI 在相同浏览器中的样式对比不等于 Tauri WebKit/WebView2、毛玻璃或完整插件生态验收。
- 同步服务的私有临时数据库测试不得访问桌面用户数据库；未实现的协议能力明确拒绝且不得宣称已兼容。
- 正式签名、公证、跨平台打包及整体性能指标以实测与 CI 为准，不用代码或单元测试完成状态替代。

## 仍不授权的动作

本决策不授予 Git 提交/推送、生产部署、操作用户账号、删除数据、强制重启用户应用或任意系统自动化的额外权限。沿用当前会话和仓库已有规则。
