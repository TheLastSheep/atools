# 01: 设置保存失败时完整恢复已应用项

**What to build:** 把系统设置应用与补偿集中为一套事务。任一设置失败后，其余成功项恢复最近保存值；持久化失败也恢复系统状态。成功保存保持当前调用次数。

**Blocked by:** None (can start immediately).

**Status:** complete

- [x] 应用快捷键与其它五项设置共用同一前向/反向命令定义。
- [x] 六个失败位置逐项覆盖，失败项不重复冒充回滚。
- [x] 补偿失败保留原失败和补偿原因；持久化失败恢复行为不变。
- [x] 现有调用入口兼容，每个新改文件不超过 500 行。
