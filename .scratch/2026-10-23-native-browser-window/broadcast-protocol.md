# Task10 implementation contract

This contract is owned by the main Agent. Workers do not change it independently. The bridge and broker are scoped to one PluginPanel instance, which owns the active plugin and its exact frame/document registry. No Node, Tauri command, origin relaxation, global app bus, polling or JSON codec is introduced.

## Payload policy

`measurePluginBroadcastPayload(value: unknown): number` is a self-contained serializable function. It accounts at most 4MiB, 8192 graph nodes, depth 64; repeated references/cycles are allowed, accessors and unsupported platform/transfer/shared-memory types reject explicitly. It never serializes to JSON. Supported cloneable structured values remain structured values. Errors are DOMException DataCloneError or QuotaExceededError (budget errors include ERR_ATOOLS_BROADCAST_BUDGET). The returned bytes are conservative budget units, not a measured heap or exact wire size.

## Envelope (all messages have __atools_broadcast_channel__: true)

All client messages additionally include the existing hosted IPC `documentNonce`, captured by the bridge factory. All host replies include `targetDocumentNonce`, checked by the recipient before releasing credits or dispatching data. This prevents old queued messages on a reused WindowProxy from joining or affecting its successor document. Host validates this nonce with captureDocumentLease, which does NOT require RPC-ready: constructors/initial posts run during initialization, after the existing FIFO hosted document-open handshake.

Client → authenticated host:

- join: `{op:'join', channelId, name}`
- leave: `{op:'leave', channelId}`
- post: `{op:'post', channelId, sequence, data}`
- ack: `{op:'ack', deliveryId}`
- dispose: `{op:'dispose'}` (this source/document only)

Host → exact source/document via the existing registry reply function:

- accepted: `{op:'accepted', channelId, sequence, error?: string}`. Release this sender's pending reservation even on rejection. A current channel dispatches messageerror on error.
- error: `{op:'error', channelId, error: string}`. Join admission failed; mark that local instance closed and dispatch messageerror.
- message: `{op:'message', deliveryId, recipients: string[], name, origin, data}`. Recipients are channel instance IDs in this one document, not arbitrary frame IDs. Emit independently cloned MessageEvent data for each still-open matching instance; then ack even when all local instances closed before delivery.

channelId format: 32 lowercase hex document-random prefix + ':' + positive safe integer counter. Host validates syntax and the source/document separately; IDs are not authority. Name is DOMString with at most 128 UTF-16 code units. sequence is a positive safe integer monotonic per bridge; host rejects replay. deliveryId is a positive safe integer generated by the host, unique within this broker lifetime. origin comes from the incoming authenticated MessageEvent, never client-supplied fields.

## Budgets and delivery

- Renderer: at most 32 live instances; outgoing at most 32 messages / 8MiB awaiting accepted replies. Check queue budget before cloning and clone before reserving. If transport.post fails, release reservation and fail explicitly. Closed channels throw InvalidStateError. No transfer/detachment is performed: WebIDL extra arguments (including a second array passed to postMessage) are ignored, while absence of the required first argument throws TypeError.
- Host: at most 256 live instances / 32 per document; prune old plugin IDs and noncurrent sources before admission. Total outstanding fanout at most 128 deliveries / 16MiB; per destination document 32 deliveries / 8MiB. Count one copy per destination document, not per local channel.
- For post: validate current sender and its registered instance, sequence, data and budget; capture current recipients (same name, same plugin, excluding exactly the sender instance); group by destination document. Preflight all destination/global budgets before any delivery so resource rejection cannot partially broadcast. Clone once to pin immutable admitted data, then use existing Window.postMessage for per-document cloning. Never retain payloads in host pending metadata after delivery submission.
- Send one delivery per destination document listing its captured instance IDs, plus one accepted reply to sender. Acknowledgements release metadata/credits only when from the exact captured destination document. A stalled receiver does not cause an unbounded queue. Failed post releases its reservation; stale sources are pruned; no timeout/retry/polling is needed. All successful post returns are void.
- Browser postMessage provides asynchronous transport. The bridge must dispatch into the plugin's own EventTarget/MessageEvent realm and separately clone data for each local recipient, with receiver mutation unable to affect another. No sender echo to its own instance, but another same-document instance receives. Late joiners receive no history. Every source's posts preserve order; do not coalesce or deduplicate application data.

## Renderer integration

`createPluginBroadcastChannelBridge(target: Window, transport: {post:..., accept:...}, measure: (value: unknown)=>number, documentNonce: string)` installs the compatibility constructor and returns `{dispose()}`. It is a self-contained serialized factory. Constructor callable only with new; require at least one name arg (ignore extras); readonly name; EventTarget add/remove/dispatchEvent, onmessage/onmessageerror; replacing a nonnull attribute handler preserves its listener registration position; close idempotent; invalid this throws TypeError. Dispose on pagehide and atools-plugin-out: disable captured objects, remove own listeners and restore the original constructor descriptor only when it still owns that property. Do not overwrite a later plugin replacement. Installing with no usable transport must leave native property untouched, rather than throwing in legacy/compiler fixtures.

Compiler initializes the factory inside the existing UTools bridge IIFE immediately after hosted IPC initialization; pass its existing private `_hostedIpcBridge.documentNonce` without publishing a new global. Replace explicit factory/payload-policy placeholders in the compiler for main, hosted and native plugin documents. Do not add factories to trusted native shell documents or change sandbox flags. Factory serialization must carry the payload policy by argument and have no transpiler-generated free helpers.

## Host integration

`createPluginBroadcastChannelHost({sources, pluginId:()=>string, post:(source,message,identity)=>boolean, captureDocumentLease:(sender,nonce)=>{assertCurrent()}, clone?})` returns `{dispatch(source,identity,data,origin): boolean, invalidateSource(source), prune(), close(), diagnostics()}`. diagnostics reports counts/bytes for deterministic tests, not payloads. clone defaults to structuredClone; a test may provide the realm clone explicitly. Capture/validate the exact existing hosted document lease for each client message; retain its nonce and lease on document records and check it in live/prune operations. Reuse sources.onFrameInvalidated for immediate document cleanup; this is an existing registry callback, not a new observer/poll.

Dispatch only after the existing authenticated message router identifies the true source/document. For lifecycle open, prune after its identity rotation; for a confirmed current hosted document close, invalidate that source. Do not invalidate current channels from a stale or incorrect close nonce. Ingress may call prune without matching a BC envelope; unknown messages return false. Panel close calls close. Main/plugin changes, source rotation, child destruction or lost source cannot free another current source's entries/credits or deliver to its successor.

## Acceptance boundaries

Use the external original Harris Snipaste 2.0.1 package; builtin/in-repo older copies are not authoritative. Fixed payload bootstrap is a separate seam; a controlled services value can isolate the channel contract but cannot prove real sidecar FS access. Preserve its exact messages, including the two different Solo type messages. Original package bytes remain unchanged. Real WebKit cross-WebView delivery and the whole business flow remain pending while native probes are deferred.
