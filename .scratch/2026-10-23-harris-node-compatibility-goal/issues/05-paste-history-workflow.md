# 05: Paste 固定历史查询与复制

**What to build:** 用户通过 ATools 使用未修改的 Paste 1.3.1 原包，检索固定文本和图片历史、预览并逐条复制/粘贴，错误操作后仍可继续。

**Dependency:** 原包桌面业务验收依赖 01 的原生运行时。用户已要求暂跳过 initialize 超时排查；独立的宿主能力和原函数契约继续推进，不能据此解除原生验收依赖。

**Status:** in_progress（宿主历史能力推进；原包桌面业务仍未验收）

- [x] 打通文本、图片、文件历史的采集投影、分页、读取、删除、按类型清空与变更通知；图片分页只传本地附件路径，不传二进制。
- [x] 通过生产前端 API 调用 Harris 原版历史镜像函数，验证三类记录、游标、重复导入和错误分页；原包源码保持不变。这是契约验收，不是完整原包 UI 验收。
- [x] 接通原版富文本复制函数要求的 Electron `clipboard.write({text,html})` 与宿主 HTML 写入；验证原函数流程和真实临时命名剪贴板的双格式、替换与清理。原生前台应用的系统粘贴仍未验收，见[本批记录](../../../output/harris-plugin-first-2026-10-23/clipboard-html/README.md)。
- [x] 补齐原图片检测函数依赖的同步 `clipboard.has` / `clipboard.read`；复用现有 read scope，验证原函数的 file-url PNG 字节复制、诊断和失败恢复，并通过 macOS UUID 临时命名剪贴板验证实际格式查询/读取/清理。其它平台原格式读取未实现，完整 UI 未验，见[本批记录](../../../output/harris-plugin-first-2026-10-23/clipboard-formats/README.md)。
- [ ] 在原包桌面路线验证图片预览、实际文件读取及单条复制/粘贴。PNG 回写仍受既有 512 KiB 限制，旧 Shelf 媒体记录没有批量回填到新增兼容历史表。

- [ ] 从正确的原包发布内容安装并打开插件，以固定文本/图片历史夹具检索。
- [ ] 验证预览、单条复制和粘贴结果与所选历史项对应。
- [ ] 覆盖无匹配或取消等一次可恢复失败，能继续查询或明确退出。
